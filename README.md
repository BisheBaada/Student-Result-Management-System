# Student-Result-Management-System

Student Result Management System
Description
A C++ application that manages student examination records using a Singly Linked List.

Features
1. Add Student
2. Delete Student
3. Search Student
4. Update Student Score
5. Display All Students
6. Calculate Average Score
7. Find Highest Score
8. Find Lowest Score
9. Input Validation
10. Duplicate Record Detection

Data Structure Used:
Singly Linked List

Technologies
1. C++
2. Code::Blocks
3. GitHub
