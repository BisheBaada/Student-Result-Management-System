# student_result_management_system

Student Result Management System
Overview:
A C++ application that manages student examination records using a Singly Linked List.

Features
1. Add Student
2. Delete Student
3. Search Student
4. Update Student Score
5. Display Results
6. Calculate Average Score
7. Find Highest Score
8. Find Lowest Score
9. Input Validation
10. Duplicate Record Detection

Data Structure Used:
Singly Linked List

Technologies
1. C++
2. Code::Blocks
3. GitHub

How to Run
1. Open StudentResultManagementSystem.cbp in Code::Blocks.
2. Build and Run the project.
3. Use the menu to manage student records.
